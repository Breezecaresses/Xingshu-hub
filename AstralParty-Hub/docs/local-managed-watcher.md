# 本机托管观战验证

当前阶段沿用已实测的 Steam 国服主端与 TapTap 官方观战客户端。新增 Rust 本机 Worker 租约管理，不创建新游戏账号、不保存游戏凭据、不开放监听端口。独立服务器账号池尚未上线。

使用方式：观战页选择“开启本机托管验证”，保持已绑定的 TapTap 账号登录大厅。主端进入 PVE 后自动读取当前真实房间和观战码，经 Worker 租约分配发送官方观战请求。收到该次分配之后、同一连接和房间的新四人快照，状态才变为 `IN_USE`。只有命令发送成功时保持 `ALLOCATING`，30 秒没有真实快照显示错误。

2026-10-19 已完成实机验证：Steam 主账号 `1556514` 的 PVE 房间 `102864`，由 TapTap 账号 `3045259` 接入。观战端重启后以新连接和新 epoch 收到四人快照，租约从 `ALLOCATING` 变为 `IN_USE`；随后切回“我的账号”释放租约，再申请本机托管，最终补丁复测的同房新快照序号从 `8` 增至 `12`，新租约再次确认使用中，数据同时转发主端。已验证账号切换、释放与同房重新申请；下一局换房和长时间运行仍需继续实测。

同房重复刷新已改为调用游戏现有的 `WatchRefreshRoomStateC2S` RPC，使用当前官方房间的 `RoomId` 和 `RoomServerId`，并等待序号增长。避免在已进入战斗时再次进入 UI 辅助方法的资源预加载流程；旧流程曾在实机重复申请时停住。完成判定以收到新快照为准，修复 RPC 等待对象未结束导致成功后仍误报超时的问题；最终同房请求在超过原 20 秒等待窗口后没有迟到错误。该修复已装入 TapTap 观战端，Steam 本轮测试局保持运行。

当前操作限制：TapTap 公告页仍不响应本次自动点击或返回键，重启后需要用户关闭公告并进入大厅。能截图不表示能可靠注入输入；具体原因尚未定位。账号进入大厅后，Hub 可直接分配和跟房，不需要手工填写观战码。

Rust `LocalWatcher` 持有租约和账号身份，前端仅持有租约 ID。一个本机 Worker 同时只允许一个持有者；重复分配复用持有者的租约，不重复发送官方加入请求。持有者通过状态轮询续期，90 秒没有续期失效。主端换房、结束对局、任一端更换连接世代或 TapTap 身份变化时，旧租约立即无法继续使用。失败可通过“重试自动观战”释放后重新申请。

切换回“我的账号”会释放托管租约，客户端继续运行；释放租约不表示退出游戏或退出官方账号。本机验证仍使用本地客户端和 TCP 数据流。远程服务模式暂停本地自动跟房，避免选择云端后又隐式启动或借用本机账号。

后续独立服务器需要增加受控 HTTP 代理、服务认证、租约保活与回收、按租约授权的真实数据流。当前 WebView CSP 未放行任意远程 HTTP 地址；远程 Provider 的单元测试只验证协议契约，不能视为云端已接通。`allocate` 契约现要求 `roomId` 和字符串 `watchCode`；缺少有效状态、账号或未过期租约字段时拒绝响应，不再默认 AVAILABLE/READY。

无头鉴权、SteamKit2 票据接纳和单账号多房仍需专项验证。首阶段迁移目标是独立 Windows 机器运行官方客户端 Worker。[Steamworks 认证文档](https://partner.steamgames.com/doc/features/auth)说明票据获取与服务端验证流程，不能据此推断游戏服务器接受第三方无头鉴权。

主要入口：`src/services/localManagedAccountProvider.ts`、`src-tauri/src/xing_shu/local_watcher.rs`、`src-tauri/src/commands/local_watcher_commands.rs`。当前本机验证仅开放 PVE。

## 跨局与资源回收（2026-10-19）

真实状态离开 RUNNING 战斗时，清空手牌真值、观战缓存及头像旁挂件；同房重开通过 StartTime 区分。Hub 收到主端结束或换房后清空旧快照、广播 session-ended，并向绑定观战端发送 WATCH_STOP。观战端仅为绑定账号和对应房间执行官方退出，等待完成后允许新加入；官方成功退出回调直接完成原有清理，不停在结束确认框。旧局 epoch 清空后也禁止回流。

当前选择是一局期间持续接收、结束退房回大厅。读取一次即退出只能获得当时快照，无法反映后续抽牌、出牌等变化。退房释放订阅，不会释放客户端全部进程内存。服务器后续应按需启动、空闲回收、同房用户共用订阅；轻量 Worker 仍需验证正常鉴权和持续订阅。现有完整真实 CardIds 来自已登录官方观战消息，尚无免登录实现。

启动和身份路由按账号中心绑定的平台和账号，非 Steam 可保存对应 exe。Bilibili、WeGame 目前只有路由逻辑，缺少本机客户端、官方安装路径及容器兼容实测，不能视为全链路支持。

针对性自动化回归已通过。当前实机复测被启动界面阻挡：TapTap 提示 10.86MB 游戏资源更新、公告自动点击无响应；Steam 启动窗口激活失败。连续两局及真实收牌/星币/治疗自动致谢仍待验证。
