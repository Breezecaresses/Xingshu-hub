# 星枢快捷键

游戏内默认按 **F1** 打开功能中心，选择左侧 **「快捷键」**。也可点击悬浮球打开功能中心；旧版悬浮球设置中的改键按钮会进入同一页。

点击某项当前按键后，按下新的键盘按键或 `Ctrl / Shift / Alt + 按键`，立即生效并保存。`Esc` 取消录入；失去窗口焦点、关闭面板、切换页面或等待 20 秒也会取消。录入期间及按键释放前不会触发星枢功能。

| 功能 | 默认按键 |
| --- | --- |
| 打开 / 收起功能中心 | F1 |
| 打开 / 收起游戏变速 | F7 |
| 快速开关加速 | 左 Ctrl，单独轻按后松开 |
| 打开 / 收起模组加载 | F8 |
| 打开 / 收起录像回放 | F9 |
| 显示 / 隐藏悬浮球 | 反引号 `（Esc 下方） |
| 输出手牌诊断日志 | Ctrl + Shift + H |
| 自由镜头向左 / 右 / 上 / 下平移 | ← / → / ↑ / ↓，按住 |
| 暂停自由镜头拖动 | Esc，按住 |

重复的组合键会显示冲突功能并保留原绑定。可以清除可选功能的快捷键；功能中心保留打开按键。每项都有「默认」，页顶「恢复全部默认」只重置星枢按键，不影响其他设置。旧版已经保存的变速、模组、悬浮球按键会保留；若旧配置之间冲突，靠后的冲突项会显示「未绑定」，可在本页重新选择。

此页修改星枢插件自己的键盘操作，不修改游戏原生按键、鼠标操作或触屏手势。安卓使用外接键盘时也可调整；触屏仍可通过悬浮球和按钮操作。

开发验证：`XingShu-Dev/tools/test_hotkeys.ps1` 使用确定性输入与偏好存储，覆盖保存重载、组合键冲突、清除恢复、输入门禁、录入取消及镜头连续操作；这些检查不代表游戏内实机验收。
