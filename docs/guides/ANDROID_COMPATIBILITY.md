# 安卓兼容预览

当前候选版本 `1.0.0-android-preview5` 是游戏内托管插件预览，保留粉黄界面、移动步数与星枢命名。安卓已暂停桌面网桥，当前手牌挂件使用游戏内已同步的数据；未来服务器手牌接入结构保留，服务器连接尚未实现。本轮另外提供手机安装助手 APK；它不是安卓 Hub 或改签游戏，不包含 Windows 原生插件。

手机端“星枢手机安装助手.apk”支持 Android 11+ 在助手内填写配对码和两种端口，通过本机无线调试完成检查、安装、更新和还原；无需电脑或 Shizuku 通知，已有 Shizuku 也可选用。电脑端“星枢安卓安装助手.exe”通过已有 ADB 选择已授权设备，无需 Python。两种工具都拒绝运行中替换，分别保存记录。手机授权、手动文件及小米目录受限的处理方法见 [手机安装与手动替换](ANDROID_PHONE_INSTALL.md)。下方旧预览记录保留为历史证据，不代表新版已重复全部对局测试。

## 修复内容

- 安卓编译不引用被游戏裁剪的 `System.Diagnostics.Process` 与 `System.Console`，进程标识改从自身 `/proc` 读取。
- 使用独立安卓版本标记与 `ANDROID_CN` 平台标识。
- 安卓悬浮球默认尺寸为 64 个界面单位，最小 48；将旧预览的 44 默认值迁移一次，自定义大小在有效范围内保留。菜单与文字缩放独立保留。
- 使用 Unity `EventTrigger` 绑定悬浮球、缩放控制和挂件拖动，避免热更新环境遗漏自定义事件接口。
- 交错手牌支持触屏点击，完整长卡在安全区域内居中放大，再点屏幕收起；异步加载的图片也会同步到详情。保留原有大小滑条与玩家切换。
- 挂件使用独立的紧凑缩放，避免沿用全屏菜单的放大倍数遮住地图。功能中心适配安全区域，旋转或安全区域改变时重新计算边界。
- 安卓思考计时使用真实时间，不依赖 Unity `timeScale`，编译产物没有 Windows 原生时钟调用。加速页只开放托管引擎，原生加速标明仅 Windows。
- 安卓不启动桌面网桥连接线程，不再每 5 秒尝试连接本机桌面端口；保留 `HAND_TRUTH_MIRROR`、`HandTruthSource` 等数据处理结构供未来独立服务器传输接入。
- 构建工具保留 Android BuildTarget 13，校验 553 个游戏成员引用与 7 个反射字段；计时、统计和进度条补丁校验通过，66,977 个既有方法体保持原样，12 个目标方法发生变化。容器中另 18 个 TextAsset 保持原样，未加入原生库。

## 构建与设备部署

需要本地 Unity 引用程序集、Mono.Cecil、MSBuild、Python 的 UnityPy 和 Android SDK `adb`。这些引用及游戏二进制未放入源码仓库。

1. 从明确选择的 ADB 设备读取原版缓存，不要将 PC 缓存写入安卓。
2. 构建：

```powershell
python tools/prepare_android_runtime.py --bundle <原版程序集缓存> --out <独立输出目录>
```

3. 在游戏大厅或关闭游戏后安装：

```powershell
python tools/android_runtime_device.py install --serial <ADB设备标识> --manifest <输出目录>/candidate.json --backup-dir <此设备的备份目录>
```

安装器先核对应用版本、当前缓存哈希和原版备份，再停止指定游戏并写入既有缓存文件；不清除游戏数据。Android 12 的缓存目录可能禁止创建新文件，所以暂存于 `/data/local/tmp`，再覆盖已有文件并校验。失败会尝试恢复并校验原版。完成后正常启动游戏即可。

4. 还原：

```powershell
python tools/android_runtime_device.py restore --serial <同一ADB设备标识> --manifest <输出目录>/candidate.json --backup-dir <同一备份目录>
```

不要在游戏更新后强行覆盖新缓存。未知哈希会停止安装，需重新核对基线。真机必须由用户自行连接并授权 ADB，缓存访问权限以实际设备为准；工具不会自动开启 root 或修改安全设置。

## 后续服务器手牌与未验证部分

按当前范围，安卓暂时取消桌面网桥配对，不需要运行 Windows Hub 或设置 `adb reverse`。未来服务器手牌应增加独立的服务端地址、账号认证和设备会话校验，再将已验证的数据送入保留的手牌处理结构。当前没有服务器地址配置、连接按钮或远程全量手牌承诺，也没有放宽桌面身份校验。

模拟器单指触控测试不能替代安卓真机、多指缩放、刘海屏和后台恢复测试；这些仍需后续设备验证。十倍思考时间覆盖本地计时，不能承诺延长服务器强制截止时间。
