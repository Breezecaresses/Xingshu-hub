# 自由镜头与原生控制的缩放交接 · r8.13 候选

## 触发与原因

用户放大或拉远地图后，点击游戏原有的移动、技能、选目标等按钮，会看到视角被拉回原版。已有日志中保存的缩放值保持不变，但 `Selection → System → Free` 等切换会恢复原版镜头参数；原生 `FreeCameraStatus.System=2` 实际仍包含棋盘定位操作。

核对本机游戏程序集：`FreeCameraStatus` 的值依次为 None=0、Player=1、System=2、MapSignal=3。原生相机仍负责定位、选目标及镜头混合，不能直接停掉这些处理来锁定缩放。

## 修正

- 将已知的棋盘托管／标记状态识别为 `NativeBoard`，保留原生定位和点击处理，并保持用户的缩放距离、视场角或正交尺寸。
- 选择目标和棋盘托管之间切换时，不再先恢复原版镜头尺寸，避免出现短暂回拉。
- 从 Cinemachine 自身的最终状态读取目标位置，不将已经由插件修正的输出相机反读为新的原生目标，避免多次应用造成偏移。
- 选择窗口关闭后，等待至少一次原生相机更新及镜头混合结束，再恢复自由平移输入，允许原生操作完整执行。
- 正式战斗与无法明确识别的镜头仍交给原生处理，返回棋盘后恢复保存的缩放；关闭自由镜头时恢复原镜头参数与回调状态。
- 更新自由镜头页说明，并记录模式切换及原生定位后的实际缩放，便于后台实测核对。

## 验证

- 直接编译生产 `MapCamera` 控制器的无界面集成测试，替身仅提供引擎输入／输出。改动前在原有 208 项中有 75 项失败，复现棋盘托管回拉、反读输出偏移及过早中断混合；修正后加入标记与选择窗口瞬间关闭场景，共 238 项通过。
- 覆盖透视与正交两种投影、五档缩放、移动、选目标、技能、标记、混合、战斗返回以及回调清理。该测试不代替真实游戏画面验收。
- 电脑四渠道与安卓候选构建、兼容检查通过。四个电脑渠道已安装 r8.13，替换前快照和替换后 SHA256 均已核对；安卓仅完成构建兼容检查，未扩大为安卓实机通过。
- Steam 国服本机启动已确认 r8.13，记录到棋盘托管和选目标状态下的实际镜头应用。156.88、369.43、491.50 等缩放档位的保存值与应用值一致；同时记录到正式战斗接管及结束后恢复保存值。
- 用户操作了原生移动／技能／选目标等按钮后反馈“可以，差不多了”。这作为本次电脑画面的实际验收，范围不扩大到每张地图、其他电脑渠道或安卓实机。
- 本轮构建、兼容与实局证据保存在 `XingShu-Dev/build/camera-zoom-20261102/`，修复暂留本机，未上传新发布。

本轮不改变自动更新签名、现有公开发布资产或游戏服务端逻辑。原始程序集、用户日志和安装前备份只在本地保存。
