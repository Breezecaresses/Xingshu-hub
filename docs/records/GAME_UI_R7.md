# R7 方向索敌与交互精修

## 行为变化

- 电脑运行时 `1.0.0-game-ui-r7`；安卓运行时 `1.0.0-android-preview6`。
- 修复怪物把身后玩家列为目标：首步使用真实箭头出口，后续每步排除来路。合法环路按实际步数计算，仍按最大10格（先行1格加剩余9格）推演，不额外计算加步技能。
- 怪物角色已创建时，方向以游戏实际绘制的箭头为准；移动开始删除箭头后等待重绘，不复用旧方向。角色尚未创建时才使用经过邻接校验的服务器方向。多个箭头或同距离先后未确认时保留候选。
- 2026-10-22 实战补修：停步后的箭头由 `ShowWalkDirections(null)` 根据当前格与来路重绘，并非始终使用 `FrontIds`。修正可见箭头正常但旧服务器方向导致一直“等待同步”的问题。修复候选尚待安装后的实战复测。
- 对局统计取消“结算金币”展示；挂件保留三排九项，右下角显示移动步数，并缩短一排高度。电脑、安卓及 Hub 历史详情同步隐藏该展示项。
- 索敌详情显示当前地图格、箭头出口与候选路径，便于对照地图复现；地图标注维持原来的简短形式。
- 游戏面板开关支持整行文字点击；滑条全宽接收点击，补全滚动区留白的事件接收。按钮增加悬停、按下、禁用反馈；取消方向键自动选中这些辅助控件。保持粉黄主题。
- Hub 优化键盘焦点、按钮点击区域、触屏最小高度、禁用状态及减少动画设置。修复点击详情窗内边距误关闭，保留遮罩关闭、Esc 和焦点返回。
- Hub 使用新星形图标：粉色星、奶白星核、黄色轨道、深色底。同步侧栏、网页图标、Windows EXE 与安装器图标源。

## 根因与证据

旧实现仅在首步排除来路，其后 BFS 会把双向邻接全部展开，可通过“前进一步再掉头”选中身后玩家。仅按格子去重还会丢失合法环路的不同来向。

本地游戏 `AstralParty.Runtime.dll` 中，`UnitLand.AdjacencyLandIds` 复制地图的 `neighborLandIds`；`CanSelectedLandId(fromLandId)` 逐格排除来路；`CharacterMove.ShowWalkDirections(frontIds)` 使用传入方向，停步时调用 `ShowWalkDirections(null)` 改为从当前格排除来路。初版 R7 只读取 `RoomPlayer.FrontIds`，遗漏停步重绘来源。当前修复只读 `_walkDirections` 中实际箭头方向，匹配当前格合法出口；位置/箭头无法匹配时等待，并以 `(previousNode, currentNode)` 记录路径搜索状态。
