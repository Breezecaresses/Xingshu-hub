# 手机手牌悬浮窗入口 · r8.12

## 原因与修正

手牌页顶部的“开启／收起挂件”是实际按钮，但创建时沿用了桌面快捷键提示的 `HotkeyBadge` 名称。手机布局按名称隐藏快捷键提示时，也把这个按钮隐藏，导致手机用户在手牌页找不到打开悬浮窗的入口。

- 按钮改为独立的 `OpenHandDockButton`，文字明确显示“打开手牌悬浮窗”或“收起手牌悬浮窗”。
- 手机布局仅隐藏不包含交互控件的快捷键提示；实际按钮仍进入手机操作区，并沿用触屏按钮尺寸。
- 继续调用原有 `HandCardDock.Toggle`，不另建一套手牌状态；保留收起、关闭后重新打开、拖动、玩家切换和点卡放大。
- 记录用户打开／收起请求，便于后台核对手机入口实际触发情况。
- 本版继续包含 r8.11 的怪物冷却记录修复及 307、308 的资料核对修正。
