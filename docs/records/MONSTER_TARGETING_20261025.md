# 怪物索敌收尾核对（2026-10-25）

## 本轮行为

- 局内入口为 `MonsterTargetRuntime → MonsterTargetPreview.Calculate → MonsterTargetMath.FindNearestCandidates`。旧单目标 `Predict` 接口仍供兼容测试使用，局内不会使用它的席位或进度决胜方式。
- 沿角色当前可见箭头先行一格，首步计入最大十格预算；每步排除刚走来的边，不以双向邻接表允许立即折返。合法环路可以沿前向绕回，不使用掉头捷径。
- 先找最近目标格，该格两至四名存活玩家均列为受击组，例如 `P1 + P3（同格全体）`。不会把同格玩家拆成互斥候选，也不会继续选更远一格作为第二次攻击。
- 不同目标格距离相同时，在首次真正分叉处按红＞蓝＞绿比较；缺少颜色映射时保留候选，不用席位或玩家排名猜测。
- 观察到本次行动的主动攻击后，显示“本回合已攻击”，不再选择后续目标。临时空行动者不会清除状态，实际换行动者、换轮或退出房间时重置。

## 本轮补齐

1. 多个箭头出口最终汇合至同一目标格时，确认的是同一受击组，显示“推演”和同格全体；只有出口会到达不同目标格，或部分出口没有目标时，才保留“候选”。
2. 出口路线未定时，不再把最短样例路线的距离显示为所有路线的精确步数；详情仍说明具体路线及步数待确认。
3. 同格玩家提示按 P1 至 P4 排列，只影响展示，不影响目标选择。
4. 地图拓扑指纹在一次映射匹配中只计算一次，仍要求完整拓扑及全部岔路出口一致才启用颜色映射。

- 已有本机只读观察确认过同格两人的“同格全体”提示，但不能代替真实攻击次数及各岔路目标对照。

- 推演使用最大骰十格；实际骰点不足或技能额外加步时，不能把此提示当成必定发生的攻击。
- 中途加载插件无法恢复未观察到的历史攻击；未知或已更新地图会保留不确定提示。
- 本轮新增的多出口汇合同组展示尚待新候选装机后的实际画面验收。
