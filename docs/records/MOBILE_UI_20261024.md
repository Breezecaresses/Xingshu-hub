- 手机页内滑条先识别手势方向，再交给原有控件。上下及斜向滑动滚动页面，不触发滑条数值或保存回调；明显左右拖动才调整数值，点按在松手时生效。手势归属锁定，跨过其他滑条也不切换控件；电脑端保留原有交互。
- 对局数据按三列三排显示九项指标，继续隐藏结算金币。固定指标卡为最大字号预留高度。
- 手机对局统计挂件默认缩放改为 80%，手牌挂件改为 50%，保留独立大小调节和已有手动值。两者不再乘用旧版全局 UI 倍率，避免旧手机配置的高倍率把挂件放大；电脑默认仍为 100% / 60%。功能窗口大小保持不变。
- 保留悬浮球，手机上绘制在浮窗上方；打开功能中心不会隐藏它。点击球仍沿用原先快捷菜单行为；浮窗外部不再使用全屏遮罩拦截游戏操作。
- 使用原有功能回调和配置读取，电脑布局保持原样。
