# 星枢 0.1.4 正式版

日期：2026-11-15。Hub 与安卓手机助手版本均为 `0.1.4`，构建序号 `2026111501`。游戏运行时为电脑 `1.0.0-game-ui-r8.30`／安卓 `1.0.0-android-preview8.30`，适配《吉星派对》`3.3.0`（资源版本 `152`）。

## 本版内容

- **项目标识与侧边栏排版修复**：仓库及双端更新源统一切换至 `Breezecaresses/AstralParty-XingShu`（含 README、Hub 顶栏与设置页、游戏内 `XingShuUICenter` 页脚、`HubUpdater.cs` 与安卓 `ReleaseUpdates.java`）；精简桌面端侧边栏页脚 GitHub 链接为 `GitHub · XingShu` 并加固 Flex 防挤压与状态文本不换行样式，避免挤压右侧版本就绪提示折行。
- **静态表情头像与图鉴保留**：Hub 角色头像、对局卡与相关展示切换为静态表情轮换；角色详情页完整保留竖版全身立绘与动态皮肤展示，图鉴继续保持资源 `152`（38 条角色配置、75 张卡牌、93 项筹码、26 条地图配置）。
- **对局回放复盘与模组工坊**：重做回放分析图表与数据表格交互并加入逐事件棋盘步进复盘（`UT_Platform_*` 地格贴图）；新增**模组 / 卡牌 / 皮肤工坊**及**在线网页版（Web Edition）**，网页版支持工坊下载与弹窗视口适配（Portal 至 `document.body`）的社区投稿，桌面版支持 SHA-256 校验与 `.xingshu-mods` 原子备份后一键安装/还原。
- **运行时与更新链路改进**：合入 `0.1.4-test` 阶段的 `IsPVEMode()` 修复、手牌真值同步改进、默认关闭的星币商店防护、国内镜像加速回退更新、分渠道登录支持以及安卓端无线 ADB / mDNS 自动发现改进。

## 验证范围

- **前端与网页构建**：`AstralParty-Hub` 执行 `npm run test:all`（`33/33` 测试套组通过）与 `npm run build:web`（`TypeScript` + `Vite` 构建及静态资源生成通过）。
- **Rust 核心单元检查**：`cargo test --lib` 通过 `187` 项（`0` 失败）。
- **游戏内运行时与引用核对**：`XingShu.Runtime.dll` Release 编译及规范卡牌注册表生成通过；`prepare_runtime_truth_fix.py` 验证 `STEAM_CN`、`TAPTAP`、`BILIBILI`、`WEGAME` 四渠道容器（各 `633` 处游戏成员引用与 `9` 项反射字段解析通过，其余 `17` 项程序集未改动）；`prepare_android_runtime.py` 验证资源 `152` 安卓候选包（`654` 处成员引用解析通过，无原生库依赖，`68408` 个既有方法体保持不变、`19` 个方法体按补丁变更，其余 `18` 项文本资源未改动）。
- **安卓安装器与分发工具检查**：`build_android_installer.py` 通过 `:app:testReleaseUnitTest`、`:app:assembleRelease` 与 `apksigner verify`；`tools/` 下的源码导出、安卓载荷、离线资源审计、手机 ZIP 绑定、桌面/安卓冲突备份恢复与自更新器等 `9` 组 Python 回归脚本（共 `76` 项测试）全部通过；桌面与安卓正式包压缩档及签名 `xingshu-update.json` 通过最终一致性与 SHA-256 校验。
- **未在本轮重新声明的项目**：TapTap / Bilibili / WeGame 实机对局与星币商店跨日真实购买、安卓真机升级实测未在本轮逐台设备重跑，不扩大宣称范围。

## 分发

电脑端发布为 `XingShu_Desktop_0.1.4.zip`（含 Hub、`星枢安装助手.exe`、四渠道桌面运行时与安卓伴侣安装器）；安卓端发布为 `XingShu_Android_0.1.4.zip`（含 `星枢手机安装助手.apk`、手动替换 `__data`、官方原版恢复文件与文档）及供自更新使用的同字节独立 APK、`*.sha256` 和 RSA 签名清单 `xingshu-update.json`。公开源码仅含本地与玩家端代码，不包含服务端、QQ Bot、私密凭据或账号数据库。
