# 星枢 0.1.2 正式热修

适配《吉星派对》3.3.0／资源 152。电脑运行时为 `1.0.0-game-ui-r8.25`，安卓为 `1.0.0-android-preview8.25`（内部版本名）。Hub 和手机助手均为 0.1.2，更新序号 2026111301。

## 修复内容

- 官方热更新再次更换托管资源容器，新容器不含星枢加载入口。本次从四个电脑渠道及安卓各自的新原版资源制作补丁，恢复悬浮球和功能中心。
- 保留官方对筹码选择、建筑卡商店、图鉴界面和匹配回调的更新，不把旧版游戏程序集直接覆盖到新资源。
- 新增开发用资源发现工具，从官方 Addressables 清单解析当前托管容器，再核对原生指纹、游戏接口和注入位置。资源编号不再是发现工具的固定限制；未知接口或未知资源仍拒绝强行覆盖。详见[兼容检查说明](../guides/RESOURCE_COMPATIBILITY.md)。
- 安卓助手继续保留顶部安装／使用说明、同位置冲突备份整理和原版还原。使用原有签名覆盖升级，保留助手数据。

## 本次验证

四个电脑渠道完成当前资源清单、原生指纹、611 个游戏成员引用、9 个反射字段和设置回调检查。每个补丁只改动 19 个目标方法，保留原方法及异常处理；其他 17 个官方托管资源逐字节不变。四渠道本机安装前保留备份，安装后 SHA256 一致。

用户人工确认 Steam 国服与 TapTap Windows 的悬浮球、功能中心及手牌页均正常。哔哩哔哩和 WeGame 本次完成文件及接口检查，尚未逐一复测游戏内全部功能。

安卓使用手机实际下载、与官方当前清单一致的资源 152。611 个成员引用通过，19 个目标方法检查通过，其余 18 个 TextAsset 不变，不包含 Windows 原生库或桌面网桥线程。手机助手 20 项单元检查通过；原有资源 026／150 与新资源 152 的路径及哈希相互隔离，未知原版被拒绝。

小米 14 Pro 已覆盖升级助手 0.1.2，写入 r8.25 前保留原版，写入后独立核对 SHA256。用户人工确认星形悬浮球、功能中心和手牌页正常。本次没有重新完成真人合作手牌、全部怪物及第三方 MOD 冲突的完整实机回归，不扩大为全功能验收。

## 下载与升级

只按设备提供两个分发包：`XingShu_Desktop_0.1.2.zip` 和 `XingShu_Android_0.1.2.zip`。电脑包合并 Steam 国服、TapTap Windows、哔哩哔哩及 WeGame，安卓 ZIP 同时包含 APK、手动替换和官方还原文件。

独立 APK 与安卓 ZIP 内 APK 完全相同，供旧助手使用原有 `xingshu-update.json` 签名清单更新。升级 Hub／手机助手后，仍需正常退出游戏，再点“安装／更新星枢”，才能更新游戏内插件。游戏官方更新完成前不要安装；未知资源不要强行使用旧还原文件。

公开源码和下载包仅包含玩家端及本地工具，不包含服务器端、QQ Bot、账号凭据、配对码、手机原始审计数据或个人运行日志。云端服务不因本次发布重启。直播隐私试用继续封存。
