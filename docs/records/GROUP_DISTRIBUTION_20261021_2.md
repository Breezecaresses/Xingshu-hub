# 星枢群发测试版 0.1.0-test.20261021.2

本次为群发测试包，不作为正式稳定版。包含 Windows 便携 Hub、Steam 国服与 TapTap 游戏内插件，以及“星枢安装助手.exe”。

## 安装

完整解压 **XingShu_0.1.0-test.20261021.2.zip**，阅读“先读我.txt”。正常退出对应游戏后，打开“星枢安装助手.exe”，选择平台与实际游戏程序，点击“安装 / 更新插件”。随后通过官方平台启动游戏；主端、观战端分别安装。Hub 需要系统 WebView2 Runtime。

适配 Windows 10/11 64位、吉星派对 **3.3.0 / 资源026**。安装助手会核对渠道和资源指纹，保留备份，支持还原与之前群测版本升级。

## 本次更新

- 手牌窗口、按钮和卡牌默认整体缩小为60%，在功能中心“手牌监视”页可调40%–120%，自动保存。少牌展开、多牌交错叠放，10张以上同排，悬停抬牌查看完整信息。
- 粉黄半透明功能中心、游戏字体、星形入口，以及统一的手牌和对局统计挂件布局。
- 地图击飞预测、怪物技能冷却和最大10格索敌候选提示；战斗中隐藏冷却，概率与名字横向显示。
- 十倍思考使用独立真实时钟；底部进度条按当前操作归属更新，避免旧计时和转发显示覆盖。
- 指向牌、技能和突击门选择保留镜头移动与自定义缩放，拉远时名字和指向线同步缩小。
- 保留图鉴、动态异画、历史战绩与星枢评分，多渠道独立目录和扩展管理。

## 测试与边界

Runtime 为 `1.0.0-game-ui-r5`，Hub 为 `0.1.0`。编译及两端成员引用检查通过；36项计时、进度归属、评分和牌扇回归，40项怪物索敌检查、24组渲染与跟房流程，以及评分/结算和扩展管理检查通过。安装、升级、还原及压缩包完整性由打包脚本验证。

完整手牌需要已登录的官方观战客户端；十倍思考只修改本地计时，服务器截止仍有效。怪物索敌为候选提示，不修改游戏AI。连续观战、自然结束与自动致谢尚未穷尽所有实机场景。
