## 底部原生进度条

从当前游戏程序集确认：`OperationTimer.ActionDownTime` 的本地操作更新与 `StartShowPlayerTimer` 的转发计时更新均写 `OperateTimeWindow.progress_OperationTime`。本地操作的完成/取消回调先调用业务委托，再清空进度条；若业务委托已开始下一操作，旧回调可清空新条。另外更新回调从可变静态字段读取最大时长，多个操作可能影响同一显示。

R4 加入当前操作归属与创建时长快照：

- 创建本地操作时登记对应闭包对象及当前时长。只有当前操作能更新或清空本地条，进度在同一操作内保持单调。
- 本地操作有效期间，转发显示不再覆盖同一进度条；本地取消或完成后释放显示，房间计时器 Dispose 时清理。
- 只替换三处本地回调的界面更新入口，保留原完成、取消、AFK、超时记录与请求顺序；不取消其他操作、不修改服务器截止。关闭十倍思考、观战和回放继续走原界面路径。
