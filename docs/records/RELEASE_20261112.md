# 星枢 0.1.1 正式版

本次发布电脑端 `XingShu_Desktop_0.1.1.zip` 和安卓手机 `XingShu_Android_0.1.1.zip`，运行时分别为 `1.0.0-game-ui-r8.24`、`1.0.0-android-preview8.24`（内部版本名），适配《吉星派对》3.3.0／资源 150。Steam 国服、TapTap Windows、哔哩哔哩 Windows、WeGame 共用一个电脑安装包，分别校验各自的程序集与资源容器。

## 已确认的修复

- 资源 150 更换了托管程序集所在的 Addressables 容器。更新四渠道容器路径、原版指纹和插件指纹，修复更新游戏后悬浮球不出现。
- 选人倒计时注册入口由 `UI.RoomHeroPanel.Refresh` 移到 `RefreshChoiceHero`。补丁按实际方法检测并要求唯一入口，兼容此前资源 026；原版代码与异常分支保留。
- 直播隐私试用已封存，本版不启动独立私密窗口。保留的旧开关不再隐藏普通手牌；试用归档与外部伴随程序均不进入下载包。
- 安装助手从发布清单读取游戏／资源版本，按渠道阻止错装或覆盖未知热更新，继续保留安装前备份与还原。
- 安卓按新版独立容器与官方资源清单构建。手机助手顶部增加详细安装说明和使用说明，可滚动阅读。
- 手机安装前检查同位置覆盖冲突；仅本版官方清单与资源容器匹配时提供“备份整理并安装”。玩家确认后，按文件 SHA256 分别保存原文件和记录，再安装星枢；其他位置的模组不移动。损坏或未知官方资源仍拒绝覆盖。

## 验证范围

Steam 国服已安装 r8.24，用户人工确认游戏内悬浮球恢复。四渠道均完成托管接口、注入入口、计时补丁和统计／怪物 CD 挂钩的静态兼容检查，611 个游戏成员引用可解析；除目标程序集外的 17 个原版托管资源保持逐字节一致。

发布复核统一了运行时内嵌渠道表与资源 150 安装清单。重建前后 2874 个有实现的方法中，仅默认渠道表读取方法的配置常量变化；游戏交互逻辑未变。打包检查会拒绝内嵌旧渠道表的候选，已验证旧候选被拒绝、四渠道新候选通过。

TapTap、哔哩哔哩、WeGame 的本次资源 150 游戏内全流程尚未逐一人工验收；不将文件兼容检查描述成实机全功能验收。新角色与地图新增配置未在本次全量重新导出，图鉴沿用上一正式版资料。

安卓候选完成相同的 611 个游戏成员引用解析，原版其余 18 个 TextAsset 不变，未引入 Windows 原生库、进程调用或桌面网桥线程。手机助手 20 项单元检查通过，其中 3 项覆盖官方清单与容器匹配、逐文件冲突备份不被后续安装覆盖、错误／损坏备份拒绝。

小米 14 Pro 已覆盖升级到助手 0.1.1，签名与既有版本一致，数据未清除。手机端安装引擎实际检查原版、备份并写入 r8.24，随后从设备独立复核候选 SHA256。用户确认顶部两份说明能打开滚动，官方游戏正常启动、星形悬浮球能打开功能中心、手牌页可用。其他品牌手机、本次真人合作云端手牌全流程与现场第三方 MOD 冲突整理尚未逐一实测；不将隔离备份检查描述为这些实机验收。

发布前还执行安装助手的隔离目录安装、重复安装、还原、未知版本拒绝、跨渠道拒绝与损坏包拒绝检查；签名更新器检查包括旧双端清单、新电脑独立清单、篡改拒绝和事务回滚。具体执行结果以本次发布操作记录为准。

## 下载与更新

电脑版首次使用完整解压后运行 `星枢安装助手.exe`。先正常退出对应游戏，再选择渠道和实际游戏程序安装。Hub 位于 `Hub/xingshu-hub.exe`，使用生产构建，无需单独启动前端服务。

本次沿用原名 `xingshu-update.json` 提供双端签名更新，Hub 和手机助手版本均为 0.1.1、构建序号为 2026111201。既有更新入口仍可使用；签名仍使用项目既有身份。0.1.1 Hub 另外支持可选的电脑独立清单，供以后需要时使用。

安卓 ZIP 同时提供手机助手 APK、手动替换与官方还原文件。GitHub 另附与 ZIP 内逐字节相同的独立 APK，供旧手机助手直接拉取更新，无需先下载整个 ZIP。升级助手／Hub 后仍需正常退出游戏，再安装对应游戏插件。

本次公开源码与下载包不包含服务器端、QQ Bot 服务端、账号凭据、用户数据库、个人运行日志或直播隐私试用归档。云端运行服务不因本次打包而重启。
