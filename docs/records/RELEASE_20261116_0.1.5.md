# 星枢 0.1.5 正式版

日期：2026-11-16。Hub 与安卓手机助手版本均为 `0.1.5`，构建序号 `2026111601`。游戏运行时为电脑 `1.0.0-game-ui-r8.30`／安卓 `1.0.0-android-preview8.30`，适配《吉星派对》`3.3.0`（资源版本 `152`）。

## 本版内容

- **修复安卓手机助手「扫描本机渠道登录票据」扫描不到票据的问题**：
  - `InstallerEngine.readChannelTokensJson()` 改用专项多标签 logcat 采集（`BN_DEBUG` / `BN_UNITY` / `BN_WARN` / `Ev_CRASH_OS`），避免高频 `Unity:V` 日志配合 `-t 4000` 尾部截断在玩家切回助手时挤掉登录阶段的 `BN_DEBUG` 行；
  - 新增运行中游戏进程 PID 过滤（`/system/bin/ps -A` + `--pid=<pid>`）及本机已安装原生渠道包 / `BnSdk` / `/sdcard/ibingniao/period/` 落盘日志兜底线索；
  - `BnSdkTokenExtractor.extractFromLogcat()` 改为两遍解析与进程关联，解决真实 Android logcat 中 `[okhttp] .../account/authorize`、`[Memory-LoginData] userSqlEntity`、`[LoginSDK] the token is:`、`[BnUnitySdk] RoleInfo` 出现在 `StatisticsPeriodHelper` / `Ev_CRASH_OS` `appid` 之前的问题，并按时间顺序覆盖保留最新轮换票据。
- **修复安卓手机助手无线配对「第三步 · ② 连接本机无线调试」无法自动识别连接端口的问题**：
  - `MainActivity.startMdnsDiscovery()` 新增监听 Android 11+ 无线调试标准连接服务 `_adb-tls-connect._tcp`（`AdbMdns.SERVICE_TYPE_TLS_CONNECT`），同时兼容 `_adb._tcp` 与 `service.adb.tls.port` 系统属性回退，解决第二步配对端口能自动识别而第三步连接端口无法自动填入的问题；
  - `AdbMdns` 增加 `NsdManager.resolveService` 串行队列与 `FAILURE_ALREADY_ACTIVE` 自动重试，防止配对服务与连接服务并发解析时互相丢弃，并在第二步配对成功后自动填入并尝试连接第三步端口、在已配对设备上支持后台静默重连。
- **继承 `0.1.4` 全部功能与修复**：包含游戏内 12 项统一快捷键设置、静态表情头像、回放步进复盘与模组工坊、`AstralParty-XingShu` 仓库与侧边栏 UI 修复以及国内镜像自更新机制（完整变更见[RELEASE_20261115_0.1.4.md](RELEASE_20261115_0.1.4.md)）。

## 验证范围

- **安卓单元检查**：`build_android_installer.py` 执行 `:app:testReleaseUnitTest`（8 个测试类共 `39` 项单元测试全部通过，含新增的 `BnSdkTokenExtractorTest` 后置 `appId`、`userSqlEntity`/`LoginSDK`、包名与 `fallbackAppId` 关联测试）、`:app:assembleRelease` 与 `apksigner verify` 通过。
- **前端构建与检查**：`AstralParty-Hub` 执行 `npm run test:all` 与 `npm run build` 通过；Rust `xingshu-hub.exe` 发布构建与版本标识同步通过。
- **打包与签名校验**：`XingShu_Desktop_0.1.5.zip`、`XingShu_Android_0.1.5.zip`、`XingShu_Android_0.1.5.apk` 及 RSA 签名清单 `xingshu-update.json` 通过 SHA-256 与构建序号一致性校验；手机真机扫码/扫描仍需用户更新 `0.1.5` 后在实体机上触发验证。

电脑端发布为 `XingShu_Desktop_0.1.5.zip`，安卓端发布为 `XingShu_Android_0.1.5.zip` 及同字节独立更新 `XingShu_Android_0.1.5.apk`、`*.sha256` 和 RSA 签名清单 `xingshu-update.json`。公开源码仅含本地与玩家端代码，不包含服务端、QQ Bot、私密凭据或账号数据库。
