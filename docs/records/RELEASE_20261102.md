# r8.17 发布记录

发布标识：`0.1.0-test.20261102.1`，更新序号 `2026110201`。
电脑插件：`1.0.0-game-ui-r8.17`；安卓插件：`1.0.0-android-preview8.17`。
游戏适配范围保持为吉星派对 `3.3.0 / 026`。
沿用现有普通 Release 更新渠道，旧客户端未开启“包含测试版”时也应能检测此版本；版本名中的 `test` 保持历史命名。

## 本轮内容

- 自由镜头保留用户缩放，原生移动、技能和目标选择不再强制拉回默认视角；战斗镜头保留官方控制。电脑用户已确认实际表现。
- 角色框旁新增各自独立的手牌入口，挂在原生头像层级；直接显示单卡，牌多轻叠，默认 80%，支持单独调节大小。
- 角色旁取消悬停和点击详情，不显示整条底框和翻页；旧的独立长卡悬浮窗继续保留。
- 原生筹码、商店、目标选择和战斗界面显示时暂时隐藏手牌及入口，关闭后恢复。实际前台窗口判定不依赖 UIManager 缓存。
- 保留前版治疗、三排统计、怪物索敌与冷却记录、原生“主播模式”和手机显示适配。

实现与证据边界见 [自由镜头记录](FREE_CAMERA_ZOOM_20261102.md) 和 [原生头像旁手牌记录](ROSTER_HAND_GRID_20261102.md)。

## 已完成验证

- 四个 Windows 渠道候选与安装文件逐一 SHA256 校验，旧版备份保留；611 个游戏成员引用与 9 个反射字段兼容检查通过。
- 头像旁手牌的布局、状态与实际窗口判定：44,112 项断言、288 组组合通过；自由镜头集成检查 238 项通过。替身测试不等于设备显示验收。
- Steam 实测捕获 75 条原生父组件记录与 96 次窗口隐藏/恢复转换，用户确认显示、遮挡和恢复正常。
- 小米 14 Pro 已完成新版插件与同签名手机助手覆盖安装。插件 SHA256 为 `0174439ead7a0bc5bcee57f41d6176128d0963a18a2f30ba6b1e42f46f06e896`；助手 APK SHA256 为 `427256312adc069c372baa4074853f6b198813c1029c6b0ca9e71cec604cd09a`。
- 手机实机观察到头像旁手牌展开、收起及原生父组件；最近日志采样 60 条父组件记录、无相关告警。用户确认按当前版本发布；未据此声称每个手机原生交互窗口和镜头按钮都逐项重测。
- 手机助手 APK 继续使用原签名，应用数据和无线调试配对身份保留。
