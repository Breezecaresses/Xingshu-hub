# 星枢 0.1.6 正式版

本次为正式版发布（替代 `0.1.5`），代码许可保持 MIT。本版全面适配《吉星派对》`3.3.0 / 资源 160`（电脑四渠道与安卓国服），打通全端登录与自动云端手牌同步，并对对局统计、手牌与点赞布局、加速标点提示、自由镜头跳转及星枢 Hub 交互排版做了完整升级。

## 版本信息与下载

- **适用游戏版本**：`3.3.0 / 资源 160`（Steam 国服、TapTap Windows、哔哩哔哩、WeGame、安卓国服）
- **版本号**：Hub 与手机助手 `0.1.6`（更新序号 `2026111901`），电脑端插件 `1.0.0-game-ui-r8.33`，安卓端插件 `1.0.0-android-preview8.34`
- [电脑端 ZIP](https://github.com/Breezecaresses/AstralParty-XingShu/releases/download/v0.1.6/XingShu_Desktop_0.1.6.zip)：含星枢 Hub、安装助手、四渠道插件与安卓配套连接组件。
- [安卓手机 ZIP](https://github.com/Breezecaresses/AstralParty-XingShu/releases/download/v0.1.6/XingShu_Android_0.1.6.zip)：含手机助手 APK、手动替换与官方原版还原文件。
- [直接安装安卓 APK](https://github.com/Breezecaresses/AstralParty-XingShu/releases/download/v0.1.6/XingShu_Android_0.1.6.apk)：与安卓 ZIP 内 APK 一致，可覆盖更新手机助手。

## 核心更新与修复

- **官方资源 160 全端适配与切场黑屏修复**：
  - 更新电脑四渠道（Steam 国服／TapTap／哔哩哔哩／WeGame）与安卓国服资源指纹、卡牌注册表及运行时清单。
  - 移除运行时中会触发原生界面意外实例化的窗口懒加载访问，并建立全量窗口观测 IL 静态门禁。
- **全端登录与云端看牌自动同步（电脑端 + 安卓端）**：
  - 手机端打通「星枢手机助手」到游戏内的双通道自动同步（无线调试/Shizuku 写临时凭据文件 + 本地 `127.0.0.1:47821` 原生 `.NET TcpClient` 环回桥），登录后一键启动游戏或游戏内点击「同步手机助手账号」即可自动完成 `/auth/mobile/claim` 换票；同时保留「QQ 绑定码」备用。
  - 修复手机助手从游戏内拉起后点击「启动游戏并同步当前账号」未切回游戏任务栈的问题（`singleTask`），并按登录渠道自动匹配目标渠道包、对 UID 不一致给出明确提示。
  - 修复安卓 IL2CPP 下 `System.DateTimeOffset.TryParse` 被裁剪导致云端手牌长期停留在“观战接入中”的问题，改用纯 C# ISO-8601 UTC 解析与非 LINQ 循环并在构建检查脚本中加入防回归拦截。
  - 精简星枢 Hub 账号页与观战页流程：登录后自动开启合作局云端手牌推送并在账号卡片直接展示状态开关，默认折叠本地双开观战设置。
- **手牌、点赞、对局统计与局内体验升级**：
  - 手牌锚点固定至角色框稳定层级，不再随头像晃动；点赞按钮默认开启全员点赞并调整到角色框居中位置（点击彩色图标取消对单人点赞，支持给自己点彩蛋赞）。
  - 对局统计重构为四玩家同屏横条表格，支持自定义勾选统计指标与静态表情头像，修复展开/折叠时的窗口位移；快捷键设置支持鼠标侧键绑定。
  - 放大怪物地面行动路径箭头指向；新增结算界面自动截图保存至本地目录。
  - 延长游戏加速模式下的右侧标点提示停留时间；修复自由镜头模式下点击右侧标点无法跳转镜头的问题。
- **星枢 Hub 界面与 Mod 安装体验优化**：
  - 支持直接将下载的 Mod 压缩包／文件拖入星枢 Hub 自动检测并一键安装。
  - 合并精简 Hub 顶部与侧边栏重复控件，界面排版更干净统一。

## 安装与更新说明

- **电脑端**：完整解压 ZIP 后运行「星枢安装助手.exe」，先正常退出游戏，再按渠道安装／更新对应插件，不要在压缩包内直接运行。
- **安卓端**：安装新版 APK 后需正常退出游戏，在手机助手内重新点击安装／更新游戏内插件再启动游戏；也可通过电脑端 Hub 的无线／USB ADB 一键更新。
- 正式版用户可直接在星枢 Hub 或手机助手内检查更新并自动升级至 `0.1.6`。
