# 两个 ZIP 与自动更新兼容验证 · 2026-10-24

## 结论

群发与手动下载保留电脑端 ZIP、安卓手机 ZIP 两个包。安卓 ZIP 包含同一版手机助手 APK、手动替换插件、官方原版还原文件及说明。GitHub Releases 另外保留与 ZIP 内字节完全相同的独立 APK，供现有手机更新器直接下载；原签名清单仍指向电脑 ZIP 和安卓 APK，不更改清单格式或客户端。

- 更新回归 9 项通过：原签名清单在额外提供安卓 ZIP 时仍选择电脑 ZIP 与 APK；保留签名篡改、包完整性、路径及备份回退检查。
