# 星枢群发测试版 0.1.0-test.20261022.2

同一 Release 的 Assets 按电脑端与安卓端提供下载：电脑端 `XingShu_Desktop_0.1.0-test.20261022.2.zip` 同时包含星枢 Hub、Steam 国服与 TapTap Windows 运行时，在安装助手中选择渠道即可；安卓端提供手机安装助手 APK，另附可选安装工具 ZIP 和手动替换 ZIP。

- Steam 国服 / TapTap Windows：保持已验证的 Runtime `1.0.0-game-ui-r6` 与 Hub `0.1.0`，本轮合为一个电脑端下载包。保留粉黄界面、交错长卡、移动步数、模组加载、10 格怪物索敌和真实思考计时。分别通过安装、重复安装、还原、旧版升级、未知缓存及损坏载荷检查；本轮没有重新进行完整对局测试。
- 安卓：Runtime `1.0.0-android-preview5`，手机助手 `0.1.0-test.20261022.2`。Android 11+ 支持直接在 APK 填写配对端口与六位码，然后填写无线调试主页面的连接端口；只连接本机，无需电脑和 Shizuku 配对通知。已有运行中的 Shizuku 仍可选用。
- 小米 14 Pro / Android 16 / HyperOS 3 实机完成 APK 内配对、连接、目录检查、官方还原及星枢安装。设备文件 SHA256 与原版、候选及备份逐一核对。小米 15 和其他厂商未逐一验证。
- 地址栏可输入端口或粘贴完整 IPv4 地址与端口。配对码不保存；配对与连接具有超时，处理结果弹窗显示。
- 手机悬浮球默认64、最小48，可独立调节；修复自动收起设置。运行时载荷沿用上版已验证预览5，没有重新修改游戏逻辑。

安装前正常退出游戏。手机助手与电脑助手都会检查适配版本和资源指纹，未知文件拒绝覆盖；保留账号数据与安装前备份。电脑包完整解压后运行“星枢安装助手.exe”，只选择对应官方渠道游戏程序。手机步骤见 [安装指南](../guides/ANDROID_PHONE_INSTALL.md)。

完整手牌仍需要已登录的官方观战客户端。安卓桌面网桥暂停，未来服务器连接尚未实现。十倍思考受服务器强制截止限制。模拟器曾有一次原生音频崩溃，原因未确认；本次不承诺解决该问题或覆盖所有系统。

这是群发测试预发布，不分发原生变速 version.dll、账号数据、配对密钥或个人日志。第三方组件及对应源码保留原有许可证。
